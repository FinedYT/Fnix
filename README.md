# Fnix

IMPORTANT! 
FNIX is an MVP project that is still in the development stage. REVERSE PROXY is not implemented (it is planned for release), ASYNC is not implemented, TREADS is poorly implemented, everything will still be improved, this is not the final product!!! 

---

What is this? 
Fnix is an experimental Python reverse proxy and HTTP server designed for learning networking and web server internals.
